# 🚀 Onyx-Development

> 🛠️ Building AOSP-Based ROMs for POCO F7 / Redmi Turbo 4 Pro

Welcome to **Onyx-Development**! 👋

This organization hosts the repositories required to build AOSP-based custom ROMs using LineageOS-based device trees for devices powered by the **Qualcomm Snapdragon 8s Gen 4 (SM8735)** platform.

* 📱 **Supported Devices:** POCO F7 / Redmi Turbo 4 Pro
* ⚡ **Platform:** Qualcomm Snapdragon 8s Gen 4 (SM8735)
* 🧩 **Base:** LineageOS Device Trees
